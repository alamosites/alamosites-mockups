# Images Directory

Upload client images here:

## Required Images

- `logo.png` — Company logo (transparent background)
- `favicon.png` — 32x32 favicon
- `apple-touch-icon.png` — 180x180 iOS icon
- `og-image.jpg` — 1200x630 social sharing image

## Recommended Folders

- `/blog/` — Blog post images
- `/products/` — Product images (Premium only)
- `/team/` — Team member photos
- `/gallery/` — Project/portfolio images

## Image Guidelines

| Type | Format | Max Size |
|------|--------|----------|
| Photos | .jpg, .webp | 500KB |
| Graphics | .png, .svg | 200KB |
| Icons | .svg | 50KB |

Optimize all images before uploading. Use https://squoosh.app for compression.
